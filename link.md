# RETRYNET — FULL PRODUCTION SOCIAL NETWORK

Ты — ведущий full-stack разработчик, системный архитектор и инженер по безопасности.

Твоя задача — превратить существующий проект RetryNet в полноценную, работающую социальную сеть.

Это НЕ демонстрационный проект.

Все функции должны быть реализованы на настоящем frontend, backend и базе данных.

Database:

- Drizzle ORM.
- Миграции.
- Транзакции.
- Индексы.
- Ограничения целостности данных.

Infrastructure:

- S3-совместимое хранилище.
- WebRTC.
- STUN/TURN.
- Переменные окружения.
- Логирование.
- Health checks.

Используй актуальные стабильные совместимые версии библиотек.
